### 2. `oa quality-loop` command (`commands/agents.py`)
- Volledig automatische kwaliteitsverbeterloop

- Stuurt gerichte feedback, wacht op update, herhaalt (max N rondes)
- `--max-iterations`, `--evaluator-model`, `--wait-timeout` instelbaar

### 3. Smart OSS model router (`spawner.py: route_oss_model()`)
- `oa run` zonder `--model` → automatische modelselectie op basis van taakanalyse
- Complexe taken → `hetzner/mixtral:8x7b`
- Lange context / research → `hetzner/mistral-nemo` (128k)
- Simpele operaties → `hetzner/mistral:7b`
- 12/12 tests groen
- Config override: `"oss_model_default"` in `~/.oa/config.json`

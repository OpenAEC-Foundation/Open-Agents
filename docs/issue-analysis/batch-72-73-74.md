## Issue #74: fix: bridge server throws FileNotFoundError for tmux when started outside tmux session

**Title:** fix: bridge server throws FileNotFoundError for tmux when started outside tmux session
**State:** OPEN
**Author:** FreekHeijting
**Labels:** bug

**Prioriteit:** critical
**Effort:** S (Small)
**Hetzner-relatie:** direct-blocker
**Sprint:** Sprint 11 (hotfix candidate)

### Analyse

**Current Status:** **APPEARS TO BE ALREADY FIXED** in the codebase.

Source file inspection (bridge.py:846–858) reveals the correct implementation:

```python
def run_bridge(port: int = 5174) -> None:
    """Start the bridge server."""
    import os as _os
    # Ensure tmux and common tools are findable regardless of how the bridge was started
    _env_path = _os.environ.get("PATH", "")
    for _p in ["/usr/bin", "/usr/local/bin", "/bin"]:
        if _p not in _env_path:
            _os.environ["PATH"] = _p + ":" + _os.environ.get("PATH", "")
    _kill_port(port)
    print(f"Open Agents bridge running on http://localhost:{port}")
    ...
```

This code:
- ✅ Ensures `/usr/bin`, `/usr/local/bin`, and `/bin` are in `PATH` before Flask starts
- ✅ Prepends missing paths to `os.environ["PATH"]`
- ✅ Resolves the root cause: `subprocess` in `check_agent()` can now find `/usr/bin/tmux`

**Root cause (from issue):** When `oa web` is started as `oa web &` (background), the parent process environment may lack standard binary paths. The Flask app would fail on `/api/agents` requests because `check_agent()` calls `subprocess` which cannot find `tmux`.

**Test coverage:** The `/api/agents` endpoint (line 132–156) calls `check_agent(rec.name)` for running agents. Without the PATH fix, this would 500 on every status poll.

### Voorstel

**Verification required:** Confirm this fix was recently merged. If issue is still open, check:
1. Current main branch HEAD — does `run_bridge()` include the PATH initialization?
2. If bridge.py in the issue description lacks this code, the fix has been applied.
3. Close issue #74 once verified + merged to main.

**Test plan:** Start bridge as `oa web & sleep 1 && curl http://localhost:5174/api/agents`. Should return agent list without 500 FileNotFoundError.

### Blokkeert

- Background/daemonized bridge launch (`oa web &`)
- Any environment where `/usr/bin` is not in PATH (Docker, limited shells, CI/CD)
- Web UI agent status polling (every 2s request would fail until self-recovery)
